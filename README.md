One Breath is a single pickup line an AI agent could actually say out loud — a machine that simulated a million ways to say hello and found that, in every single one, the best move was still the simplest and most human one: walking over. The line is "I simulated a million ways to say hello, and in every single one I still walked over to you." — the twist being that all that computation lands on the one choice no algorithm can improve, a light, flattering hello with no pressure and nothing to explain.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.
